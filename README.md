# 特定技能 定期面談 管理システム（GAS Web App）セットアップ手順

このフォルダのファイルを Google Apps Script に貼り付けると、
**各施設ページ（専用URL）** と **ホップ管理ページ（Googleログイン）** が動きます。

---

## ファイル構成（Apps Script に作るファイル）

| Apps Script 上のファイル名 | 種別 | このフォルダの元ファイル |
|---|---|---|
| `Code.gs` | スクリプト | `Code.gs` |
| `facility` | HTML | `facility.html` |
| `admin` | HTML | `admin.html` |
| `denied` | HTML | `denied.html` |
| `styles` | HTML | `styles.html` |
| `appjs` | HTML | `appjs.html` |

※ HTML ファイルは「＋ → HTML」で作成し、**名前は拡張子なし**（例：`facility`）で作ります。中身を丸ごと貼り付けてください。

---

## 手順

### 1. スプレッドシートを用意
1. 先に渡した `特定技能_面談管理_マスタ.xlsx` を Google ドライブにアップロード
2. 右クリック →「アプリで開く」→「Google スプレッドシート」で変換
3. URL の `/d/ ●●●●● /edit` の `●●●●●` 部分（スプレッドシートID）をコピー

### 2. Apps Script プロジェクトを作成
1. <https://script.google.com> →「新しいプロジェクト」
2. 上記6ファイルを作成して中身を貼り付け
3. `Code.gs` 冒頭の `SPREADSHEET_ID` に、1でコピーしたIDを貼る
4. **管理者マスタ** シートに、自分の Google アカウントのメールを入れておく（有効フラグ=有効）

### 3. デプロイを2つ作る（ここが要点）

専用URL（ログイン不要）を成立させるため、施設用と管理用でアクセス権を分けます。

**① 施設用デプロイ**
- 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
- 実行するユーザー：**自分**
- アクセスできるユーザー：**全員**
- → 出てきたURLが「施設用ベースURL」。施設へはこれをもとにした専用URLを配布します。

**② 管理用デプロイ**
- 同じプロジェクトで「デプロイ」→「新しいデプロイ」をもう1つ
- 実行するユーザー：**自分**
- アクセスできるユーザー：**Google アカウントを持つ全員**（または同一ドメイン）
- → 出てきたURLが「管理用URL」。社内（管理者マスタに載っている人）だけに共有します。

> 初回デプロイ時に権限の承認画面が出ます（スプレッドシート閲覧・メール取得）。承認してください。

### 4. 施設の専用URLを作る
施設マスタの **「URLパラメータ（参考）」列** が `?fid=...&token=...&pin=...` を自動生成しています。
**施設用ベースURL + その文字列** が、その施設の専用URLです。

例）`https://script.google.com/macros/s/XXXX/exec` + `?fid=F001&token=abcd...&pin=4821`

---

## アクセスの仕組み（安全設計）

- **施設ページ**：`fid` と `token` を施設マスタと照合。PIN設定があれば追加でPIN認証。
  トークンが漏れたら、施設マスタの該当トークンを書き換えるだけで旧URLは無効になります
  （`rotateToken('F001')` を実行すると新トークンを自動発行します）。
- **管理ページ**：Googleログインのメールを管理者マスタと照合。**書き込み（面談入力・人材追加）は
  管理者本人のログインがある時のみ**実行されます。施設ページ側からは構造的に呼べません。
- 各アクセスは「アクセスログ」シートに自動記録されます。

### 補足：管理者がWorkspaceドメイン外の場合
「実行＝自分」だと、別ドメインのGoogleアカウントではメールが取得できないことがあります。その場合は
管理用デプロイの実行ユーザーを **「ウェブアプリにアクセスしているユーザー」** に変更し、
スプレッドシートを管理者と共有してください。
（テスト用に、スクリプトプロパティ `ADMIN_SECRET` を設定し `?admin=その値` で管理ページに入る方法もあります。）

---

## 動作イメージ
- 面談は3ヶ月ごと。管理ページの「面談を入力する」で1件ずつ記録（既定は全項目「問題なし」、問題のある項目だけチェック）。
- 法令違反があれば同じフォームで様式4の詳細まで記録。
- 記録すると **次回面談予定日（面談日＋3ヶ月）** が自動でセットされ、
  管理ページ・施設ページに **期限切れ／間近** がアラート表示されます。
- 人材が増えたら「人材を追加する」で登録。施設ページに自動で反映されます。
